# Non-Functional Requirements

**Baseline:** v0.1  
**Status:** PROPOSED

### NFR-SEC-001
CivilBonus shall not implement or store Google account passwords.

### NFR-SEC-002
Authentication configuration shall use approved Firebase project/application configuration and authorized production domains.

### NFR-SEC-003
User-facing errors shall not disclose secrets, credentials or unnecessary internal diagnostics.

### NFR-TRACE-001
Material product changes shall be traceable from requirement to implementation and verification.

### NFR-CHANGE-001
Architecturally significant changes shall be documented by an Architecture Decision Record (ADR).

### NFR-CHANGE-002
Implementation shall occur through version-controlled changes suitable for review before becoming the accepted baseline.

## To be specified

Performance, accessibility, browser support, availability/recovery, privacy/data retention, observability and scalability targets require explicit product decisions before they are treated as contractual requirements.
