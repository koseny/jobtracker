# CivilBonus Engineering Documentation

This directory is the controlled specification baseline for CivilBonus.

## Development contract

CivilBonus changes follow this traceability chain:

Product intent → requirement → UX/system behaviour → architecture/data/security impact → implementation → verification → accepted baseline.

Structural or architectural decisions require explicit approval before implementation. Coding agents may propose changes but must not silently establish new product or architecture conventions.

## Baseline v0.1

The initial baseline records the authentication experiment already proven in production and establishes the documentation structure for subsequent increments.
